# Security Policy

## Supported versions

This project is under active development. Security fixes are applied to the
`main` branch and included in the next release.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, use GitHub's **private vulnerability reporting**:

1. Go to the [Security tab](https://github.com/Miragon/camunda-cockpit-sso/security)
   of this repository.
2. Click **Report a vulnerability** to open a private advisory.

This creates a private channel between you and the maintainers. Please include:

- a description of the vulnerability and its impact,
- steps to reproduce or a proof of concept,
- affected version(s) and any known mitigations.

We will acknowledge your report, keep you informed of the progress towards a fix,
and coordinate the disclosure timeline with you. Thank you for helping keep this
project and its users safe.
